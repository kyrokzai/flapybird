# Flappy Trump

Браузерная аркада в жанре «flappy»: мультяшный Трамп с крылышками летит над Вашингтоном и пролетает между кирпичными стенами.

## Как играть

Откройте `index.html` в любом браузере — сборка и сервер не нужны.

- **Клик / тап / Пробел / ↑ / W** — взмах
- **M** — включить/выключить звук
- Пролетел через проём — +1 очко. Задел стену или землю — «YOU'RE FIRED!»

## Что внутри

- Физика как в классике: гравитация, резкий взмах, наклон в пике, фиксированный шаг 60 FPS
- Медали: бронза (10), серебро (20), золото (30), платина (40)
- Рекорд сохраняется в браузере
- Случайно выбирается день или ночь
- Вся графика рисуется кодом на canvas, звуки синтезируются через Web Audio — внешних картинок и аудио нет
