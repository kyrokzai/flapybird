# QARATUN (бывш. БАТЫР01) — заметки для работы над игрой

Браузерная 3D-игра в жанре Archero на Three.js r128. Название — **QARATUN** (Қара түн, «чёрная ночь», подпись «Восстание древнего зла»); ключ сохранения остаётся `batyr01.save`. Модели в `assets/*.js` (GLB в base64).

**Код правь в `src/`, а не в `index.html`.** `index.html` собирается командой `npm run build` из `src/shell.html` и `src/game/*.js` (по порядку имён файлов, всё внутри одного замыкания). После правок обязательно `npm run build` и коммит обоих. CI (`.github/workflows/pages.yml`) проверяет `npm run check` и выкладывает игру на GitHub Pages (ветка `gh-pages`).

**Сначала прочитай `docs/GDD.md`**: там цели, аудитория, решения владельца и план по этапам. Новые фичи делай по этому плану.

## Инструменты для геймдева
- Если подключён плагин **parallax-threejs**, используй его для отладки Three.js и шейдеров (сцена, консоль, состояние WebGL, пиксели) и для визуальных регресс-тестов после изменений графики.
- Плагин **Unity** нужен только при переносе игры на Unity (например, для мобильного приложения). Для текущей браузерной версии не используй.
- Без плагинов проверяй изменения через Playwright с `--use-angle=swiftshader` и открытием `index.html#test` (режим без урона, `Mergen.goto(n)` прыгает в комнату, `Mergen.give(item)` выдаёт бонус, `Mergen.dieNow()` открывает экран воскрешения, `Mergen.tab('gear'|'talents'|'quests', popup)` открывает вкладку меню и окно `item`/`energy`/`daily`, `Mergen.end(won)` завершает забег, `Mergen.save` — сохранение, `Mergen.tut` — состояние обучения, `Mergen.music` — текущая тема музыки, `Mergen.crateList` и `Mergen.tp(x, y)` — ящики комнаты и телепорт героя, `Mergen.survival()` — запуск арены выживания, `Mergen.wave` — номер волны; заставка в тестовом режиме не показывается; энергия в тестовом режиме не тратится). **Баланс меняй только с прогоном `Mergen.sim({...})`** — ориентиры в `docs/GDD.md`, раздел 13.

## Правила
- Ветка разработки: `claude/mergen-archer`. Flappy Trump живёт в своей ветке, её не трогать.
- Тексты для игрока — на русском, казахском и английском (`STR`, поля `name`/`desc` с `ru`/`kz`/`en`).
- Анимации: модель со скелетом делается так: GLB → `3d_rigging` в Higgsfield (одна анимация за запуск, ~8 кредитов; спрашивать у владельца) → `tools/merge-anims.mjs` собирает клипы в один GLB и убирает смещение корня. Пример — `makeBatyrRig`/`animateRig` в `17-models-and-enemies.js`.
- Новые 3D-модели: сжимать через gltf-transform (weld, simplify ~1.6%, текстуры 1024 px для персонажей и зданий, 512 px для мелких предметов), класть в `assets/<name>.js`, добавлять в `MODEL_KEYS` и `LOAD_ORDER`.
- Сначала грузится то, что видно в меню (небо меню, батыр, конь), остальное — в фоне.
- Сохранения: объект `Save` (ключ `batyr01.save`, поле `v`). Меняешь формат — подними `SAVE_VERSION` и добавь шаг в `Save.upgrade()`.
- **Интерфейс (премиальный стиль):** все экраны рисуются на 2D-холсте шириной 360. Высота логического экрана `H` переменная (640–860, по пропорциям устройства), отступы выреза/«домой» — `SAFE.t` / `SAFE.b`. Верх привязывай к `SAFE.t`, низ — к `H - SAFE.b`; окна, свёрстанные под 640, центрируй через `shiftUI(oy, fn)` (сдвигает и зоны нажатия). Камера боя сохраняет ширину обзора (`G3.baseFov`).
- Компоненты: `panel()` (тёмная панель с золотой каймой), `button()` (без `col` — золотая; с `col` — тёмная с оттенком; `shape: 'hex'`, `icon`, `sub`), `txt(..., { f: 'head' | 'logo' })`, `goldFrame`, `diamond`, `frameBand`, `drawLogo`. Цвета текста — из `T` (`T.text`, `T.muted`, `T.gold`), не тёмные.
- Шрифты: Montserrat (интерфейс), Cormorant SC (заголовки), Cinzel (только логотип QARATUN, в нём нет кириллицы). Все, кроме Cinzel, проверены на казахских буквах; Manrope и Cinzel их не поддерживают.
- Учитывай `REDUCED_MOTION` (prefers-reduced-motion) для новых анимаций.
- **Арена выживания** (`31-survival.js`): стадион — 16-я запись в `ROOM_DEFS` (`arena: true`), режим забега `run.mode === 'survival'` (`isSurv()`), сложность врагов — `diffLevel()` (в сюжете = номер комнаты, на арене растёт с волной). Сюжетный баланс и `Mergen.sim` арену не трогают.
- **PWA:** `manifest.webmanifest`, `sw.js` (страница — сначала сеть, ассеты — кэш с фоновым обновлением, CDN — кэш), значки `icons/`. CI копирует их в `gh-pages`. Если меняешь стратегию кэша, подними `CACHE` в `sw.js`.
- **Звук:** записанные эффекты — `assets/sfx.js` (`window.SFX_PACK`, mp3 в base64), музыка — `assets/music_menu|battle|boss.js`. `Sound.play(name, vol, gap)` играет запись или возвращает false (тогда звучит синтез), `Sound.musicTrack()` включает тему по `Sound.mode`. Новые эффекты: подрезать тишину, нормализовать пик до −1 dB, mono 64 kbps.
- **Профиль и рейтинг** (`32-profile.js`): `Save.data.profile`, `stats`, `glory`, `tickets` (Save v5). Слава — `gloryFor(won)`, записывается один раз за забег в `recordRun(won)` (из `endRun` и выхода из паузы). Лиги `LEAGUES`, лестница героев эпоса `LEGENDS` (это не игроки). Арена **бесконечная**: волны идут, пока батыр не падёт (таймера нет, на табло — время забега), одновременно на поле не больше `SURV_ALIVE` = 18 врагов; вход по билету (`spendTicket`), открыта при `arenaUnlocked()`. Награды `survivalRewards()`: сундук за каждые 5 волн (до 6; каждый третий редкий, с 30-й волны первый — эпический), слава +60 за каждые 10 волн, достижение «Покоритель арены» — 20 волн.
- **Атмосфера** (`33-atmosphere.js`): настроение комнаты `MOODS[n]` (свет солнца/неба, тон панорамы, цветокоррекция `grade` с `tint` в шейдере, фонари, дымка, свет батыра), тени `blobShadow`, трава комнат `buildRoomGrass`, полёт монет/опыта в HUD `flyToHud`/`drawFlyers`.
- **Иконки** (`34-icons.js`, `assets/icons.js` = `window.ICON_PACK` с webp): снаряжение 176 px (вырезано по контуру), навыки и таланты 128 px (круг). Ключи — id из `GEAR`, `SKILLS`, `TALENTS`. Если картинки нет, рисуется старый векторный значок.
- **Элиты** (`35-elites.js`): `maybeElite` в `spawnEnemy`, `eliteAbsorb`/`eliteTick`/`eliteDeath`; шанс `eliteChance()`. Баланс проверен симуляцией (новичок ~19%).
- **Достижения и «Жол»** (`36-goals.js`, Save v6: `ach`, `frames`, `profile.frame`, `pass`): `ACH`, `achUpdate()`, `grant(rw)`; пропуск — `PASS` (30 ступеней по `PASS_STEP` славы с `pass.start`). Тосты — `toasts`.
- **Комикс** (`37-comic.js`): `assets/comic.js` = `window.COMIC_PACK` (массив 4 data-URL, 9:16), тексты `COMIC_TEXT`, флаг `Save.data.introSeen`. Тест: `Mergen.comic()`.
- **Батыр в меню** (`assets/batyr.js`): тот же воин владельца из комикса, но со скелетом Tripo и клипами `run`, `dance_05`, `dance_02`, `box_02` (~88 тыс. треугольников, цвет 2048 px, рельеф 1024 px, meshopt). Собирается через `makeBatyrRig(model, true)`; клип выбирает игрок кнопкой слева от батыра (`MENU_ANIMS`, `drawAnimSwitch` в `30-menu-hud.js`, выбор в `Save.data.settings.menuAnim`, тест `Mergen.menuAnim(id)`). «Стойка» — кадр бега, выпрямленный в `archerPose` (ветка `o.menu`: ноги `standLegs`, руки `AP.*rest`). Плащ отвязан от костей рук скриптом `tools/detach-cloak.mjs` (иначе он разлетается при движении рук). Конвейер: weld → simplify 0.045 (error 0.004) → `detach-cloak` → `tools/strip-root-motion.mjs` → `texn.mjs` 2048/1024 → resample → `gltf-transform meshopt`. Боевая версия (`hero.js`) — тот же файл, simplify ещё ×0.45, только клип `run`, текстуры 1024/512. Ракурс — `MENU_CAM`. Меню рендерится с pixel ratio до 2 (кроме «Низкой»), трава меню ставится только в поле зрения камеры. `Mergen.prof` — среднее время кадра 3D и 2D.
- **Модели владельца (Tripo)** сжимаются скриптом `texn.mjs in out colorPx normalPx` (+ `gltf-transform meshopt`): `prop_birch` (берёзы в парках, у ворот и в меню), `lm_portal` (портал с драконом и бегущими людьми — ориентир в комнатах 4–5, `LM_HEIGHT.portal`), `civ_woman` (горожанки у ворот и заборов, `38-civilians.js`: машут, а после зачистки радостно подпрыгивают). Тест: `Mergen.models`, `Mergen.g3`.
- **Реквизит владельца** (`prop_gate`, `prop_hedge`, `prop_fence`, `prop_lamp`, `prop_chest`): резные ворота (узлы `frame`/`doorL`/`doorR`, створки — шарниры `G3.doors` в `themeWalls`), живая изгородь в парках и чугунная решётка на улицах (кладутся сегментами вдоль стен), фонари вдоль улиц, сундук вместо ящика с добычей (`makeCrateModel`). Повторяющиеся модели ставь через `propInstances(name, places, pivot)` — один InstancedMesh на меш (квантованные меши `mergeStatic` не склеивает). Ворота и фонарь разрезаны `tools/split-prop.mjs`.
- **Оптимизация:** `mergeStatic()` (`39-merge.js`, нужен `BufferGeometryUtils.js` r128) после постройки комнаты склеивает неподвижные предметы с одинаковым материалом в один меш и замораживает матрицы (вызовы отрисовки −30…−55%). Всё, что потом двигается, добавляй после этого вызова или передай в список исключений. Динамическое разрешение `watchRes` (`G3.resScale` 0.6–1) снижает чёткость рендера при FPS < 45. **Холсты меняют размер только в начале кадра, прямо перед отрисовкой** (`needResize`, `watchPerf`/`watchRes` до `render()`): смена размера стирает холст, и стёртый холст между кадрами давал чёрное моргание. События `resize` только ставят флаг.
- **Окрестности** (`40-outskirts.js`, `buildOutskirts`): за стенами комнаты — текстурная земля (`outskirtGround`, вместо плоского цвета `THEMES.outer`), продолжение дороги / тропинки / дорожки / настила на юг и на север (`outskirtStrip`), берёзы и кусты в парках, кварталы домов и машины на улицах, пальмы на пляже. Ряды фонарей и деревьев по бокам идут от `zN - 8` до `zS + 12` (ореолы фонарей в `applyMood` — те же ряды).
- **Контур персонажей в сумерках:** `addRim(material)` в `makeEnemyModel` добавляет подсветку краёв (общий `G3.rimUni`, цвет задаёт `applyMood` по `MOODS[n].light`, днём 0). Оборачивает чужой `onBeforeCompile`, поэтому ставит свой `customProgramCacheKey`.
- **Размеры:** ведьмы (жезтырнак, албасты, мыстан) крупнее волков — масштабы в `add*Model`, высоты в `MODEL_H`; батыр в бою — воин владельца из Tripo (`assets/hero.js`, `makeBatyrRig(model, true)`, масштаб 1.75).
- **Боевой батыр** (`hero`): модель воина из комикса со скелетом Tripo. Пока есть только клип `run` (смещение корня убрано, бег на месте); стойка — кадр 15 бега + дыхание, отдача при попадании и падение при смерти сделаны в `animateRig` (`m.pose`). Стрельба — `archerPose`: кости рук и ног поворачиваются к направлениям из `AP` (в системе героя: +x вперёд, +z его правая сторона), лук в левой руке — `makeHandBow`, тетива идёт за правой рукой по циклу выстрела (`o.shot` = `player.atkAnim / 0.18`). Новые клипы (Text to Motion в Tripo, тот же скелет) добавлять в этот же GLB по именам `idle`, `shot`, `hit`, `death` — `makeBatyrRig` подхватит их сам. Старый лучник `batyr_rig` больше не загружается.
- **Степь QARATUN** (`41-steppe.js`): все 15 сюжетных комнат — степь вокруг Астаны в трёх вариантах темы: `steppe_gold` (1–5, закат), `steppe_night` (6–10, луна и туман), `steppe_blood` (11–15, кровавое затмение, светящиеся трещины `G3.stpCracks`). Пол `steppeFloor` (трава, трещины, тропа `steppePath`), препятствия `steppeProp` (`#` — балбал / камень с петроглифами, `Y` — юрта / сломанная телега / мёртвое дерево, `~` — тёмный пруд или лавовый разлом), частокол с факелами и знамёнами `steppeWalls`, за воротами большая юрта (или череп быка на воротах в затмении), россыпь вокруг `steppeScatter`. **Модели владельца `stp_*`** (`assets/stp_*.js`, Tripo, сжаты weld → simplify → `texn.mjs` → meshopt): частокол секциями `propInstances('stp_palisade')`, факел, знамя, ворота-череп (`steppeSkullGate`: арка + створки из `prop_gate`), большая юрта, валун, стела, тамга, телега, мёртвое дерево, куст, череп, кости, колесо, казан. Каждый строитель берёт модель через `stpHas`/`stpModel`, а пока она не загрузилась — рисует свою фигуру из кода. Анимации огня и трещин — `G3.stpAnim` (подключаются после `buildLife`), подвижное исключено из `mergeStatic` через `G3.stpDyn`. Небо — панорамы владельца `assets/sky_steppe_gold|night|blood|dark.js` (`window.SKY_STEPPE_*`), собранные из широких картинок скриптом `tools/mkpano.py` (картинка + зеркальная копия = полный круг, солнце/луна/затмение за воротами); пока файл не загрузился, небо рисует код (`steppeSkyTex`). Город — только силуэты вдали (`lm`, без Байтерека). Цвета вариантов — `STP`, настроения — `MOODS` 1–15.
- **20 комнат, 4 акта** (`TOTAL_ROOMS = 20`): 1–5 золото (босс Дәу), 6–10 ночь (Жалмауыз), 11–15 затмение (Айдахар), 16–20 «Чёрная ночь» `steppe_dark` (фиолетовая тьма, своя панорама с фиолетовым сиянием `sky_steppe_dark.js`, синий огонь факелов; финал — «Чёрный Айдахар», `bossMul: 2` и `bossName` в `ROOM_DEFS`). Арена — `ROOM_DEFS.length + 1`, её настроение `MOODS[SURV_ROOM]`.
- **Дальность стрельбы** `SHOT_RANGE = 480` px (было ~900): батыр целится только во врагов в этом радиусе (`pickTarget`), стрелы и перья орла летят ровно на эту дистанцию, рикошет живёт 0,5 с; бот симуляции подходит ближе, если в радиусе никого нет.
- **Рост сложности** (`08-rooms.js`): урон врагов +7,5% за комнату, здоровье `1 + 0.16·(n−1) + 0.03·max(0, n−10)²`, с 9-й комнаты добавляются враги из набора акта (2 в 9-й, ещё по одному каждые три комнаты), ящик с добычей — один на комнату. Боссы: Дәу 360, Жалмауыз 650, Айдахар 1000, Чёрный Айдахар ×1,8. Проверено `Mergen.sim` (20 комнат, после уменьшения дальности): новичок 17% (140 забегов), таланты «Сила 6, Здоровье 6» — 49% (80), смерти распределены по всей главе.
- **Пруды** `steppePonds`: соседние клетки `~` — один пруд со скруглёнными краями, берегом, камышом и камнями (в затмении — лавовый разлом).
- **Длина комнат ×1.5:** в `06-data.js` середина каждой раскладки повторяется ещё раз (в комнатах 1–3 без врагов, 4–7 — один враг, дальше — два, в комнатах боссов — пусто). Проверено `Mergen.sim`: новичок 21% (100 забегов), таланты «Сила 6, Здоровье 6» — 60%.
- **Память на телефонах и продолжение забега:** грузятся только модели степи, меню и арены (старые городские лежат в `assets/`, но в `LOAD_ORDER` их нет); панорамы неба 2048×1024 без мип-уровней, при смене неба старая копия освобождается из видеопамяти (`setPano`). Модели врагов, боссов, коня, юрты, балбала, орла и Қыдыр ата пережаты `tools/texf.mjs` (без карты металла/шероховатости, враги — цвет 512, боссы и конь — 1024 + рельеф 512; **координаты вершин не квантуются**, их читают вершинные шейдеры анимаций): текстуры моделей 65 → ~25 млн пикселей, файлы −30 МБ. При входе в бой `freeMenuGpu()` выгружает из видеопамяти батыра меню, коня, берёзы и небо меню (в меню они подгружаются сами). Пул вспышек `G3.fxPool` ограничен 48 и делит одну геометрию. Если телефон всё же перезапустит страницу, забег не теряется: в начале каждой комнаты `snapRun()` пишет `Save.data.runSnap` (Save v7), в меню появляется кнопка «Продолжить · комната N» (`resumeRun()`), снимок стирается в `recordRun`; если вместо «Продолжить» начать новый забег, `settleSnap()` выплачивает добычу прошлого (монеты, кристаллы, сундуки за пройденные комнаты) как при поражении.
- **Память (продолжение):** музыка больше не распаковывается в `AudioBuffer` (три темы занимали ~80 МБ PCM): `Sound.addPack` делает из mp3 blob-ссылку, тему играет один `<audio>` через `createMediaElementSource` → `musicGain` (`initStream`, `fadeEl`; любое касание перезапускает остановленную тему — iOS разрешает старт только из жеста; при скрытой вкладке пауза). Эффекты по-прежнему декодируются. Небо комнат хранится сжатыми данными `G3.skyData` и распаковывается только для текущего акта (`skyReady`), остальные панорамы выгружаются; небо меню — как раньше. Карта теней на телефонах 1024 (на ПК 2048). Столб света над добычей — общая геометрия на размер (`G3.beamGeos`). Тест: `Mergen.audio`.
- **Стрелы и снаряды пачкой** (`18-projectiles-pickups.js`): обычные стрелы рисует `drawArrows` — по одному InstancedMesh на древки, наконечники, оперение и шлейфы (цвет по стихии через `instanceColor`) и одно облако точек на свечения (до `ARROW_MAX` = 320); выстрелы врагов — `drawBullets` (InstancedMesh на каждый вид + точки). Отдельные модели остались только у перьев орла. Свечения одноразовых спрайтов — `glowShared` (общий материал). Искры ограничены `700 · Q.fx`, цифры урона — 36 на экране; у врагов прозрачные кольца и свечения прячутся (`visible`). Модели врагов упрощены до 7–12 тыс. треугольников, боссов — до ~14 тыс.; декор за частоколом без теней, частокол отбрасывает тень только на «Высокой». Стресс-тест (комната 17, ~150 стрел, 50 снарядов, 25 врагов): вызовов отрисовки ~335 на кадр вместо ~1800, треугольников ~1 млн вместо ~2,4 млн. Тест: `Mergen.skill(id, n)` выдаёт навык, `Mergen.counts` — стрелы, снаряды, искры.
